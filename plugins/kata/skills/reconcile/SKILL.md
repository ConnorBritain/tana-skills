# Reconcile Kata

Read [the operating contract](../../references/contract.md), then hydrate its
live Tana guide. Use the requested Thought link(s), or the live Review queue if
none are supplied. No link is needed for a queue-wide review. State bounded
coverage and paginate; do not claim an entire queue was checked after a partial
result.

Follow the contract's reconciliation procedure. An invocation authorizes
verified Tana observation/status repair; it does not authorize new execution
records or destination status changes. If the user requests read-only review,
honor that instead. Check exact linked records before semantic searches.

Resolve stale route questions when exact destination evidence proves that route
already happened. Keep unrelated choices open. Return only real remaining
decisions and access/broken-link exceptions, with source links. Do not ask the
user to redo work that is already evidenced in its owning app.
