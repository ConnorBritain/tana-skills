# Review Kata decisions

Read [the operating contract](../../references/contract.md), hydrate the live
guide and reconcile the requested Thoughts before presenting questions. With no
link, use the Review queue. Reconciliation may resolve a stale question without
another approval. Do not convert optional metadata work into a user obligation.

For each remaining choice, show the question, proposed action, destination and
what will change. The user may answer here; editing Tana first is not required.
Persist their answer with provenance when they make it. If they explicitly ask
to apply existing answers, re-read those answers and the concrete proposal;
clarify only missing scope or a material change rather than asking for the same
permission again. Do not treat agent-written answers as human authorization.

Apply authorized work through the relevant connector with the contract's
duplicate and concurrency checks. Read back the result, link it to the source
candidate and reconcile Processing. When no answer has been submitted, leave
the question unanswered. Report exact remaining choices; do not imply the
cloud decision-submission path has shipped.
